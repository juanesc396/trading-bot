# trading-bot
### Overview
This trading bot is developed in Python and leverages various libraries for data manipulation, technical analysis, real-time data processing, and error handling. It is designed to execute trades based on predefined strategies while providing real-time notifications.

### Technologies Used
The bot utilizes the following key libraries:

- Pandas and NumPy – For efficient data manipulation and numerical computations.
- TA-Lib – For technical analysis indicators and functions.
- Websockets – To enable real-time data streaming.
- Tenacity – To implement robust error handling and request retries.
- Discord.py – To send notifications regarding executed trades and error alerts.

### Features
- Real-time market data processing.
- Automated trade execution.
- Error handling and retry mechanisms.
- Discord integration for trade and error notifications.
